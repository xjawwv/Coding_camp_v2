# Course Content

Materi course dibuat langsung pada source page di `pages/course`.

Saat ini panel admin tidak menyediakan CRUD course maupun upload materi. Dokumentasi ini menjadi catatan format yang dapat digunakan ketika halaman course manual dikembangkan kembali.

Format yang disarankan:

```text
# Judul Course
## Judul Lesson
Paragraph materi.
`inline code`
```javascript
console.log("Hello");
```
```

Jangan menggunakan raw HTML dari input pengguna tanpa sanitasi.
