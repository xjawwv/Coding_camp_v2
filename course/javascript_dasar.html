Dasar Pemrograman JavaScript

Fondasi wajib sebelum lanjut ke framework atau library apapun, baik untuk pengembangan web, mobile, maupun backend. Materi ini membahas variabel, tipe data, operator aritmatika, array, object, dan function dari nol.

01

Variable

Variable adalah tempat menyimpan nilai supaya bisa dipakai ulang di bagian lain program. JavaScript modern punya tiga cara deklarasi: let, const, dan var. Pakai const sebagai default, ganti ke let hanya kalau nilainya memang perlu berubah. Hindari var karena scope-nya lebih longgar dan sering bikin bug tidak terduga.

const namaPengguna = "Ilan";
let jumlahPoin = 10;

jumlahPoin = jumlahPoin + 5;

console.log(namaPengguna);
console.log(jumlahPoin);

Tipe data dasar di JavaScript ada string, number, boolean, null, undefined, object, dan array. JavaScript bersifat dynamically typed, jadi tipe variable ditentukan otomatis dari nilai yang disimpan, bukan dideklarasikan manual.

Deklarasi const mencegah variable ditimpa ulang, tapi kalau isinya object atau array, isi di dalamnya tetap bisa diubah.

02

Aritmatika & Operator

Operator aritmatika dipakai untuk melakukan perhitungan matematis: tambah, kurang, kali, bagi, sisa bagi, dan pangkat. Operator ini jadi dasar dari hampir semua logika program, dari kalkulasi harga sampai validasi kondisi.

aritmatika.js
const a = 10;
const b = 3;

console.log(a + b);
console.log(a - b);
console.log(a * b);
console.log(a / b);
console.log(a % b);
console.log(a ** b);

Selain operator aritmatika, ada juga operator perbandingan (===, !==, >, <) dan operator logika (&&, ||, !) yang dipakai untuk percabangan kondisi seperti if dan else.

03

Array

Array menyimpan kumpulan nilai dalam satu variable, diakses lewat index yang dimulai dari angka 0. Array di JavaScript punya banyak method bawaan untuk manipulasi data seperti menambah, menghapus, memfilter, dan mentransformasi isinya.

array.js
const bahasaPemrograman = ["JavaScript", "Python", "Go"];

bahasaPemrograman.push("Rust");

const bahasaHurufBesar = bahasaPemrograman.map(function (item) {
  return item.toUpperCase();
});

console.log(bahasaPemrograman[0]);
console.log(bahasaHurufBesar);
  • push() dan pop() menambah atau menghapus dari akhir array
  • map() mengubah setiap item lalu mengembalikan array baru
  • filter() menyaring item berdasarkan kondisi tertentu
  • find() mencari satu item pertama yang cocok dengan kondisi

04

Object

Object menyimpan data dalam pasangan key dan value, cocok untuk merepresentasikan entitas dengan banyak properti seperti data user, produk, atau course. Akses properti object bisa pakai dot notation atau bracket notation.

object.js
const course = {
  judul: "Dasar Pemrograman JavaScript",
  level: "beginner",
  durasi: "6 minggu",
  aktif: true
};

console.log(course.judul);
console.log(course["level"]);

course.durasi = "8 minggu";

Object bisa berisi array, function, bahkan object lain di dalamnya (nested object). Struktur data hasil fetch API pada umumnya berbentuk array of object seperti pada course.json.

05

Function

Function membungkus sekumpulan logika yang bisa dipanggil berulang kali tanpa menulis ulang kodenya. JavaScript punya beberapa cara penulisan function: function declaration, function expression, dan arrow function.

function.js
function hitungTotal(harga, jumlah) {
  return harga * jumlah;
}

const hitungDiskon = (harga, persen) => {
  return harga - (harga * persen / 100);
};

console.log(hitungTotal(50000, 3));
console.log(hitungDiskon(150000, 10));

Arrow function tidak punya this sendiri, dia mewarisi this dari scope di luarnya. Ini penting dipahami sebelum masuk ke konsep class atau event handler.
